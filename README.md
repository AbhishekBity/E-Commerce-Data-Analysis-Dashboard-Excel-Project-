# 📊 E-Commerce Data Analysis Dashboard (Excel Project)

This project is an end-to-end **E-Commerce Sales Analysis Dashboard** built using **Microsoft Excel**.  
The dashboard helps understand **sales performance, top countries, top products, monthly trends, and customer revenue contribution**.

---

## 🔥 Project Highlights
- Cleaned, transformed, and analyzed **536,639+ orders**.
- Identified **Top 10 countries**, **Top 10 products**, and **Top 10 customers**.
- Built **interactive charts, slicers, KPIs, and dashboards**.
- Performed **monthly trend analysis** and country-wise comparison.
- Showed total revenue of **$9.7M+** using dynamic calculations.

---

## 🛠 Tools Used
- **Microsoft Excel**
  - Pivot Tables
  - Pivot Charts
  - Slicers
  - Data Cleaning
- Conditional formatting

---

## 📌 Key Insights From Dashboard
### 🔸 Total Orders: **536,639**
### 🔸 Total Revenue: **$9,726,003+**
### 🔸 Last Order Date: **10 December 2011**

### 📍 Top Findings
- **United Kingdom** contributed the highest number of orders.
- **DOTCOM POSTAGE** and **REGENCY CAKESTAND** were the highest-selling products.
- **Top 20 monthly trend** shows highest sales in November and December.
- Top customers contributed **$256K+** in revenue.
